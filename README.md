# Flight-Price-Prediction
# 항공권 가격 상승 위험도 및 구매 타이밍 안내 서비스

## 프로젝트 개요

본 프로젝트는 공공데이터를 활용하여 항공권 가격 상승 가능성과 구매 타이밍 위험도를 분석하는 서비스입니다.

공공데이터에는 실제 항공권 판매 가격이 제공되지 않기 때문에, 본 프로젝트는 특정 항공권의 정확한 가격을 예측하는 것이 아니라 항공 수요, 운항 공급, 공휴일, 환율, 운항 리스크 등의 요인을 기반으로 항공권 가격이 상승할 가능성이 높은 시점인지 판단하는 방식으로 설계되었습니다.

사용자는 선택한 노선과 출발 시점에 대해 가격 상승 위험도가 낮음, 보통, 높음 중 어느 수준인지 확인할 수 있으며, LLM 기반 설명을 통해 해당 결과의 주요 근거를 이해할 수 있습니다.

---

## 프로젝트 목적

항공권 가격은 수요, 공급, 성수기, 공휴일, 환율, 운항 상황 등 다양한 요인에 따라 변동됩니다. 그러나 일반 소비자는 현재 항공권을 구매해야 할지, 더 기다려도 되는지 판단하기 어렵습니다.

본 프로젝트는 공공데이터 기반의 수요·공급·시기적 요인을 분석하여 소비자가 항공권 구매 시점을 판단하는 데 도움을 주는 것을 목표로 합니다.

---

## 주요 기능

### 1. 항공권 가격 상승 위험도 산정

공공데이터를 기반으로 항공권 가격 상승에 영향을 줄 수 있는 요인을 분석합니다.

분석 요인은 다음과 같습니다.

* 여객 수요 증가 여부
* 운항편 수 및 공급석 수 변화
* 공휴일 및 연휴 인접 여부
* 성수기 여부
* 환율 변화
* 지연 및 결항 등 운항 리스크

최종 결과는 다음 3단계로 분류합니다.

* 낮음
* 보통
* 높음

---

### 2. 구매 타이밍 위험도 안내

가격 상승 위험도 결과를 바탕으로 사용자가 항공권 구매를 빠르게 고려해야 하는지, 조금 더 지켜봐도 되는지 안내합니다.

예시 결과는 다음과 같습니다.

* 가격 상승 위험도 낮음: 대기 가능
* 가격 상승 위험도 보통: 가격 변동 확인 필요
* 가격 상승 위험도 높음: 빠른 구매 고려 권장

---

### 3. LLM 기반 설명 제공

LLM은 위험도 산정 결과를 사용자가 이해하기 쉬운 자연어 설명으로 변환합니다.

단순히 “위험도 높음”이라고 안내하는 것이 아니라, 해당 결과가 나온 이유를 함께 제공합니다.

예시 설명:

> 해당 노선은 최근 여객 수요가 증가하고 있으며, 출발일이 연휴와 가까운 시점입니다. 또한 운항편 공급이 충분히 늘지 않은 구간으로 판단되어 가격 상승 위험도가 높은 편입니다. 일정이 고정되어 있다면 빠른 구매를 고려하는 것이 좋습니다.

## 위험도 산정 기준

본 프로젝트는 실제 항공권 판매 가격이 아닌, 공공데이터 기반 요인을 점수화하여 가격 상승 위험도를 산정합니다.

| 요인     | 판단 기준                         |
| ------ | ----------------------------- |
| 수요 증가  | 여객 수가 전월 또는 전년 대비 증가한 경우      |
| 공급 부족  | 운항편 수 또는 공급석 수가 감소한 경우        |
| 연휴 인접  | 출발일이 공휴일 또는 연휴와 가까운 경우        |
| 성수기    | 여름휴가, 명절, 연말연시 등 여행 수요가 높은 시기 |
| 환율 상승  | 주요 통화 환율이 상승한 경우              |
| 운항 리스크 | 지연, 결항, 악천후 가능성이 있는 경우        |

위 요인을 종합하여 가격 상승 위험도를 낮음, 보통, 높음으로 분류합니다.

## LLM 적용 방식

LLM은 가격 상승 위험도 산정 결과와 주요 근거 데이터를 바탕으로 사용자 친화적인 설명을 생성합니다.

LLM의 역할은 다음과 같습니다.

* 위험도 결과 요약
* 주요 산정 요인 설명
* 구매 타이밍 안내
* 대기 또는 빠른 구매 판단 근거 제공
* 일정 변경 시 고려할 점 안내

LLM은 항공권 가격을 직접 예측하지 않으며, 공공데이터 기반 분석 결과를 자연어로 설명하는 역할을 수행합니다.

## 기대효과

1. 공공데이터 기반으로 항공권 가격 상승 가능성에 영향을 주는 요인을 분석할 수 있습니다.
2. 한국 공휴일, 명절, 연휴, 출발 공항 특성을 반영한 구매 판단이 가능합니다.
3. LLM을 통해 분석 결과를 사용자가 이해하기 쉬운 자연어 설명으로 제공할 수 있습니다.
4. 실제 항공권 가격 데이터가 없는 상황에서도 수요·공급·시기·리스크 기반의 구매 위험도 안내 서비스를 구현할 수 있습니다.
5. 출처가 명확한 공공데이터를 활용하여 프로젝트의 신뢰성과 재현 가능성을 높일 수 있습니다.

## 한계점

1. 공공데이터에는 실제 항공권 판매 가격이 제공되지 않으므로 정확한 항공권 가격 예측은 어렵습니다.
2. 본 프로젝트의 결과는 가격 자체가 아니라 가격 상승 위험도에 대한 안내입니다.
3. 항공사 내부 예약률, 잔여 좌석 수, 실시간 운임 정책은 외부에서 직접 확보하기 어렵습니다.
4. 운항편 수와 여객 수는 가격 상승 가능성을 설명하는 보조 변수이며, 실제 가격 변동을 보장하지 않습니다.
5. LLM 설명은 공공데이터 기반 산정 결과를 바탕으로 생성되며, 근거 없는 가격 단정은 하지 않습니다.
