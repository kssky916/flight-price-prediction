# LLM 기반 항공권 구매 타이밍 의사결정 지원 서비스 사업계획서

## 1. 사업 개요

### 1.1 서비스명

**LLM 기반 항공권 구매 타이밍 의사결정 지원 서비스**

### 1.2 사업 정의

본 서비스는 공공데이터 기반의 항공 수요, 공급, 공휴일, 환율, 운항 리스크 데이터를 분석하여 항공권 가격 상승 위험도를 산정하고, LLM을 활용해 사용자의 항공권 구매 타이밍 의사결정을 지원하는 서비스이다.

본 서비스는 실제 항공권 판매 가격을 직접 예측하는 서비스가 아니다. 공공데이터에는 항공권 실시간 판매가, 항공사 내부 예약률, 잔여 좌석 수, 운임 정책 데이터가 제공되지 않기 때문에, 본 사업은 공공데이터로 확보 가능한 수요·공급·시기·외부 리스크 요인을 기반으로 항공권 가격 상승 가능성을 낮음·보통·높음으로 분류하는 방식으로 설계한다.

사용자는 출발 공항, 도착 국가 또는 도착 공항, 출발 예정일을 입력하면 해당 조건의 가격 상승 위험도와 구매 타이밍 안내를 받을 수 있다. LLM은 분석 결과를 바탕으로 왜 빠른 구매를 고려해야 하는지, 왜 대기해도 되는지, 어떤 요인이 위험도에 영향을 주었는지를 자연어로 설명한다.

---

## 2. 과제 선정 배경

항공권 가격은 고정된 가격이 아니라 수요, 공급, 출발일까지 남은 기간, 성수기, 공휴일, 환율, 운항 상황 등 다양한 요인에 따라 변동된다. 소비자는 같은 노선의 항공권이라도 검색 시점과 출발일에 따라 다른 가격을 확인하게 되며, 현재 구매하는 것이 유리한지 더 기다리는 것이 유리한지 판단하기 어렵다.

기존 항공권 비교 서비스는 현재 조회 가능한 가격을 비교하거나 가격 알림을 제공하는 데 집중되어 있다. 그러나 소비자 입장에서는 단순 최저가 확인보다 “지금 사야 하는지”, “기다리면 위험한지”, “연휴나 수요 증가로 가격이 오를 가능성이 있는지”를 판단하는 것이 더 중요하다.

본 과제는 실제 항공권 가격 데이터 확보의 한계를 고려하여, 공공데이터만으로 구현 가능한 항공권 구매 타이밍 의사결정 지원 서비스로 방향을 설정한다. 이를 통해 항공권 가격 자체를 단정하지 않고, 가격 상승 가능성에 영향을 줄 수 있는 요인을 분석하여 소비자의 구매 판단을 돕는다.

## 3. 문제 정의

### 3.1 소비자 문제

- 항공권 현재 가격이 비싼 편인지 판단하기 어렵다.
- 기다리면 가격이 내려갈지, 오히려 더 오를지 판단하기 어렵다.
- 공휴일, 연휴, 성수기, 수요 증가, 공급 부족 등 가격 상승 요인을 직접 확인하기 어렵다.
- 여러 항공권 비교 사이트를 반복 검색해야 하므로 시간과 노력이 많이 든다.
- 가격 예측 또는 추천 결과가 있더라도 왜 그런 판단이 나왔는지 이해하기 어렵다.

### 3.2 데이터 문제

- 공공데이터에는 실제 항공권 판매 가격이 제공되지 않는다.
- 항공사 내부 예약률, 잔여 좌석 수, 실시간 운임 정책은 외부에서 확보하기 어렵다.
- 상용 항공권 API는 인증, 비용, 호출 제한, 사용 조건 문제가 발생할 수 있다.
- 초보 개발팀이 단기간에 실시간 가격 예측 서비스를 구현하기에는 범위가 크다.

### 3.3 해결 방향

본 프로젝트는 정확한 항공권 가격 예측이 아니라, 공공데이터 기반의 가격 상승 위험도 산정으로 문제를 해결한다. 노선별 여객 수요, 운항편 공급량, 공휴일 및 연휴 인접 여부, 환율 변화, 운항 리스크를 종합적으로 분석하고, LLM이 이를 사용자 친화적인 구매 타이밍 안내 문장으로 변환한다.

## 6. 주요 기능

### 6.1 항공권 가격 상승 위험도 산정

공공데이터 기반으로 항공권 가격 상승에 영향을 줄 수 있는 요인을 점수화한다.

분석 요인은 다음과 같다.

- 여객 수요 증가 여부
- 운항편 수 변화
- 공급석 수 변화
- 공휴일 및 연휴 인접 여부
- 성수기 여부
- 환율 변화
- 지연 및 결항 등 운항 리스크
- 출발 공항 및 목적지 권역 특성

최종 위험도는 다음 3단계로 분류한다.

| 위험도 | 의미 |
|---|---|
| 낮음 | 가격 상승 요인이 크지 않아 대기 가능 |
| 보통 | 가격 변동 가능성이 있어 지속 확인 필요 |
| 높음 | 가격 상승 위험이 높아 빠른 구매 검토 권장 |

---

### 6.2 구매 타이밍 안내

가격 상승 위험도 결과를 바탕으로 사용자가 항공권 구매를 빠르게 고려해야 하는지, 가격 변동을 더 지켜봐도 되는지 안내한다.

예시 안내는 다음과 같다.

| 위험도 | 구매 타이밍 안내 |
|---|---|
| 낮음 | 현재 조건에서는 가격 상승 위험이 크지 않으므로 추가 확인 후 구매 가능 |
| 보통 | 수요 또는 공급 요인에 따라 가격 변동 가능성이 있어 지속적인 가격 확인 권장 |
| 높음 | 연휴, 수요 증가, 공급 부족 등으로 가격 상승 위험이 높아 빠른 구매 검토 권장 |

---

### 6.3 LLM 기반 설명 기능

LLM은 위험도 산정 결과와 주요 근거 데이터를 바탕으로 사용자 친화적인 설명을 생성한다.

LLM의 역할은 다음과 같다.

- 사용자 자연어 입력 해석
- 출발지, 도착지, 출발일 등 조건 구조화
- 위험도 결과 요약
- 주요 산정 요인 설명
- 구매 타이밍 안내
- 대기 또는 빠른 구매 판단 근거 제공
- 일정 변경 시 고려할 점 안내
- 근거 없는 가격 단정 방지

예시 설명:

> 해당 노선은 최근 여객 수요가 증가하고 있으며, 출발일이 연휴와 가까운 시점입니다. 또한 운항편 공급이 충분히 늘지 않은 구간으로 판단되어 가격 상승 위험도가 높은 편입니다. 정확한 항공권 가격을 단정할 수는 없지만, 일정이 고정되어 있다면 빠른 구매를 고려하는 것이 좋습니다.

---

### 6.4 What-if 시뮬레이션

사용자가 출발일이나 조건을 변경했을 때 위험도가 어떻게 달라지는지 비교한다.

예시 질문:

- “하루 뒤에 출발하면 위험도가 낮아질까?”
- “연휴 전날 말고 평일에 출발하면 어떨까?”
- “도쿄 대신 오사카로 가면 수요가 덜 몰릴까?”
- “일본 노선 중 위험도가 낮은 도착지는 어디야?”

시뮬레이션 결과는 가격 숫자가 아니라 위험도 변화로 제공한다.

예시 결과:

> 기존 출발일은 연휴 2일 전으로 가격 상승 위험도가 높게 산정되었습니다. 출발일을 3일 뒤로 변경하면 연휴 인접 요인이 완화되어 위험도가 보통 수준으로 낮아질 수 있습니다.

---

### 6.5 Multi-Agent 기반 관점별 분석

본 서비스는 LLM을 단순 설명 도구로만 사용하는 것이 아니라, 여러 관점의 분석 결과를 분리하여 구매 의사결정을 지원한다.

Agent 구성은 다음과 같다.

| Agent | 역할 |
|---|---|
| 수요 분석 Agent | 여객 수 증가율, 목적지 권역 수요, 해외관광객 추이 분석 |
| 공급 분석 Agent | 운항편 수, 공급석 수, 항공사 수 변화 분석 |
| 일정/연휴 Agent | 공휴일, 명절, 대체공휴일, 연휴 인접 여부 판단 |
| 외부 리스크 Agent | 환율, 날씨, 지연·결항 등 외부 리스크 분석 |
| 의사결정 Agent | 각 Agent의 결과를 종합하여 위험도와 구매 타이밍 안내 도출 |

Multi-Agent 구조는 실제 복잡한 자율 에이전트 시스템이 아니라, MVP 단계에서는 관점별 분석 모듈로 구현한다. 각 모듈이 산출한 결과를 최종 의사결정 모듈이 종합하고, LLM이 이를 자연어로 설명하는 방식이다.

## 8. 데이터 활용 방식

### 8.1 수요 분석

노선별 항공통계와 지역·국가별 항공통계를 활용하여 특정 노선 또는 목적지 권역의 여객 수요 증가 여부를 분석한다.

활용 변수 예시:

- 월별 여객 수
- 전월 대비 여객 증가율
- 전년 동월 대비 여객 증가율
- 목적지 국가별 여객 수요
- 국민 해외관광객 수

---

### 8.2 공급 분석

공항별 항공통계와 운항 현황 데이터를 활용하여 특정 출발 공항 또는 노선의 운항편 수, 공급석 수 변화를 분석한다.

활용 변수 예시:

- 운항편 수
- 공급석 수
- 항공사 수
- 시간대별 운항편 분포
- 단기 운항편 공급량

---

### 8.3 수요 대비 공급 분석

항공권 가격 상승 위험도 판단에서 중요한 것은 수요와 공급의 균형이다. 여객 수요가 증가하는데 운항편 수나 공급석 수가 충분히 늘지 않는 경우, 수요 대비 공급이 부족한 상황으로 해석할 수 있다.

활용 변수 예시:

- 편당 여객 수
- 여객 증가율 - 운항편 증가율
- 여객 증가율 - 공급석 증가율
- 목적지 권역 수요 증가 여부
- 출발 공항 공급 변화

---

### 8.4 시기적 요인 분석

특일 정보 데이터를 활용하여 출발일이 공휴일, 명절, 대체공휴일, 연휴와 가까운지 판단한다.

활용 변수 예시:

- 공휴일 여부
- 연휴 인접 여부
- 공휴일까지 남은 일수
- 명절 여부
- 성수기 여부

---

### 8.5 외부 비용 요인 분석

환율 정보를 활용하여 국제선 항공권 및 해외여행 비용의 원화 기준 부담 증가 가능성을 판단한다.

활용 변수 예시:

- USD/KRW 환율
- JPY/KRW 환율
- EUR/KRW 환율
- 전월 대비 환율 변화율

---

### 8.6 운항 리스크 분석

운항 현황과 기상 데이터를 활용하여 지연, 결항, 악천후 가능성을 보조적으로 판단한다.

활용 변수 예시:

- 운항 상태
- 지연 여부
- 결항 여부
- 강수 여부
- 풍속
- 단기 날씨 위험도

## 9. 위험도 산정 방식

본 프로젝트는 실제 항공권 판매 가격이 아닌, 공공데이터 기반 요인을 점수화하여 가격 상승 위험도를 산정한다.

### 9.1 위험도 산정 기준

| 요인 | 조건 | 점수 |
|---|---|---:|
| 수요 증가 | 여객 수가 전월 또는 전년 대비 증가 | +2 |
| 공급 부족 | 운항편 수 또는 공급석 수 감소 | +2 |
| 수요 대비 공급 부족 | 여객 증가율이 운항편 또는 공급석 증가율보다 높음 | +2 |
| 연휴 인접 | 출발일이 공휴일 또는 연휴와 가까움 | +2 |
| 성수기 | 여름휴가, 명절, 연말연시 등 여행 수요가 높은 시기 | +1 |
| 환율 상승 | 주요 통화 환율 상승 | +1 |
| 운항 리스크 | 지연, 결항, 악천후 가능성 | +1 |

### 9.2 위험도 등급

| 총점 | 위험도 | 안내 |
|---:|---|---|
| 0~2점 | 낮음 | 가격 상승 요인이 크지 않음 |
| 3~5점 | 보통 | 가격 변동 가능성 있음 |
| 6점 이상 | 높음 | 가격 상승 위험이 높음 |

### 9.3 산정 결과 활용

위험도 점수와 등급은 LLM 설명 생성의 입력값으로 활용한다. LLM은 산정 결과를 기반으로 구매 타이밍 안내 문장을 생성하며, 가격을 임의로 예측하거나 단정하지 않는다.
